💾 Firmware — Portería A (v2.6 Láser)

⚠️ Conectar el Nano por USB. Subir con Arduino IDE o arduino-cli. Seleccionar placa: Arduino Nano · ATmega328P (Old Bootloader si es clon chino). Serial a 115200 baud (igual que la app v2.6).
/* * RAX RUSH — Portería A (v2.6 Láser) * Arduino Nano V3 + KY-008 (emisor 650nm) + Receptor láser de tubo * Protocolo: READY:A → GOAL:A a 115200 baud * Detección: edge detection (sin ISR, sin 38kHz — igual que v2.5) */ const byte EMISOR_LASER = 3; // KY-008 pin S const byte SENSOR_LASER = 7; // Receptor tubo OUT // ⚠️ Ajustar según el módulo (verificar con multímetro): // HAZ_PRESENTE = (digitalRead == LOW) o (digitalRead == HIGH) const bool HAZ_PRESENTE_LEVEL = HIGH; bool hazAnterior = false; bool listo = true; unsigned long ultimoGol = 0; const unsigned long BLOQUEO_GOL = 700; inline bool hazPresente() { return (digitalRead(SENSOR_LASER) == HAZ_PRESENTE_LEVEL); } void setup() { Serial.begin(115200); pinMode(EMISOR_LASER, OUTPUT); digitalWrite(EMISOR_LASER, HIGH); // láser encendido pinMode(SENSOR_LASER, INPUT); delay(400); hazAnterior = hazPresente(); Serial.println("READY:A"); } void loop() { bool haz = hazPresente(); unsigned long ahora = millis(); // El balón cortó el haz → GOL (flanco, sin ISR) if (hazAnterior && !haz && listo && (ahora - ultimoGol > BLOQUEO_GOL)) { ultimoGol = ahora; listo = false; Serial.println("GOAL:A"); } // Se rearma cuando el balón sale del haz if (haz) listo = true; hazAnterior = haz; // sin delay(): loop rápido (~2µs por lectura) }

⚠️ Notas Importantes

🔴 Seguridad láser — El KY-008 es láser Clase 3R (<5mW). NO apuntar a los ojos. Montarlo bajo en la portería y con el cabezal en modo LÍNEA (dispersa la energía). Apagar el láser (S → LOW) cuando no haya partido.
⚠️ Alineación emisor ↔ receptor — El haz debe entrar derecho al tubo del receptor. Las bases 3D tienen ranuras M3 (±5mm) para ajustar en sitio sin reimprimir. El haz visible facilita la alineación: se ve el punto/línea roja.
✅ CH340 en Windows — Los Nanos clon usan chip CH340. Windows los reconoce como "USB-SERIAL CH340 (COMx)". Si no aparece, instalar driver CH340.
⚠️ Identificar COM — En RAX SOCIAL: COM3 = Portería A, COM4 = Portería B. Si se reconectan, pueden cambiar. Usar etiqueta física en cada Nano.
⚠️ Old Bootloader — Los Nanos clones chinos suelen usar "Old Bootloader" (optiboot antiguo). Si la subida falla, seleccionar: Processor: ATmega328P (Old Bootloader)
🔌 GND común — Todos los GND deben estar conectados: Nano GND, KY-008 GND y receptor GND, más el raíl negativo de la protoboard.
